# MCP-инструменты

Сервер предоставляет 6 инструментов для работы с дыхательными сессиями.

## list_my_breath_sessions

Компактный список дыхательных сессий текущего пользователя. Возвращает только основные поля каждой сессии (`id`, `description`, `complexity`, `timeOfDay`, `shared`) без массива упражнений. Для полной информации о конкретной сессии используется `get_breath_session`.

| Параметр | Тип | Обязательный | Описание |
|----------|-----|:------------:|----------|
| `page` | number | нет | Номер страницы (начиная с 1) |
| `pageSize` | number | нет | Количество записей на странице |

**Пример ответа:**

```json
{
  "data": [
    {
      "id": "uuid",
      "description": "Утреннее дыхание",
      "complexity": 2,
      "timeOfDay": "morning",
      "shared": false
    }
  ],
  "total": 42,
  "page": 1,
  "pageSize": 10
}
```

**API-эндпоинт:** `GET /breath_sessions/list`

---

## get_breath_session

Полная информация о конкретной сессии, включая массив упражнений со всеми шагами.

| Параметр | Тип | Обязательный | Описание |
|----------|-----|:------------:|----------|
| `id` | string | да | ID сессии |

**API-эндпоинт:** `GET /breath_sessions/:id`

Возвращает полный объект `BreathSession` с полями `exercises`, `createdAt`, `updatedAt` и др.

---

## create_breath_session

Создание новой дыхательной сессии. AI-ассистент проектирует программу упражнений на основе цели пользователя, желаемой сложности и времени суток; инструмент выполняет валидацию и отправку в API.

| Параметр | Тип | Обязательный | Описание |
|----------|-----|:------------:|----------|
| `description` | string | да | Название или описание сессии |
| `exercises` | array | да | Массив упражнений (минимум 1) |
| `timeOfDay` | enum | нет | `"morning"`, `"midday"` или `"evening"` |
| `shared` | boolean | нет | Сделать сессию публичной (по умолчанию `false`) |

**Структура упражнения:**

| Поле | Тип | Описание |
|------|-----|----------|
| `steps` | array | Последовательность шагов (минимум 1) |
| `steps[].type` | enum | `"inhale"`, `"exhale"` или `"hold"` |
| `steps[].duration` | number | Длительность в миллисекундах |
| `restDuration` | number | Отдых между повторами (мс) |
| `repeatCount` | number | Количество повторов (минимум 1) |

**Типичные диапазоны:** длительность шагов 1000–10000 мс, отдых 1000–5000 мс, повторы 1–10. Поле `complexity` вычисляется на сервере и не передаётся.

**API-эндпоинт:** `POST /breath_sessions`

## classify_session_time_of_day

Анализирует сессию и формирует промпт для AI-классификации времени суток. Возвращает форматированное описание сессии с инструкцией определить `timeOfDay`.

| Параметр | Тип | Обязательный | Описание |
|----------|-----|:------------:|----------|
| `sessionId` | string | да | ID сессии для анализа |

**Логика работы:**

1. Загружает сессию по ID через `GET /breath_sessions/:id`
2. Форматирует описание, упражнения и шаги в структурированный текст
3. Возвращает промпт с инструкцией выбрать одно из значений: `morning`, `midday`, `evening`

AI-ассистент анализирует возвращённый текст и предлагает классификацию.

---

## set_session_time_of_day

Обновляет поле `timeOfDay` у указанной сессии.

| Параметр | Тип | Обязательный | Описание |
|----------|-----|:------------:|----------|
| `sessionId` | string | да | ID сессии |
| `timeOfDay` | enum | да | `"morning"`, `"midday"` или `"evening"` |

**API-эндпоинт:** `PATCH /breath_sessions/:id`

**Тело запроса:** `{ "timeOfDay": "morning" }`

Возвращает обновлённую сессию.

---

## classify_all_sessions

Пакетная классификация всех неразмеченных сессий.

Параметры: нет.

**Логика работы:**

1. Загружает все сессии (с пагинацией, до 50 за запрос)
2. Фильтрует сессии с `timeOfDay === null`
3. Форматирует каждую неразмеченную сессию
4. Возвращает AI-ассистенту список для анализа с инструкцией:
   - Предложить `morning` / `midday` / `evening` для каждой
   - Запросить подтверждение у пользователя
   - Вызвать `set_session_time_of_day` для каждой подтверждённой классификации

Если все сессии уже размечены — возвращает сообщение «нечего классифицировать».

## Формат ответов

Все инструменты возвращают результат в стандартном MCP-формате:

```typescript
{
  content: [{ type: "text", text: "..." }]
}
```

При ошибке:

```typescript
{
  isError: true,
  content: [{ type: "text", text: "Error: ..." }]
}
```
