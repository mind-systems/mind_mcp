# MCP-инструменты

Сервер предоставляет 4 инструмента для работы с дыхательными сессиями.

## list_my_breath_sessions

Получение списка дыхательных сессий текущего пользователя.

| Параметр | Тип | Обязательный | Описание |
|----------|-----|:------------:|----------|
| `page` | number | нет | Номер страницы (начиная с 1) |
| `pageSize` | number | нет | Количество записей на странице |

**Пример ответа:**

```json
{
  "data": [
    {
      "id": "uuid",
      "description": "Утреннее дыхание",
      "timeOfDay": "morning",
      "exercises": [...],
      "complexity": 2,
      "shared": false
    }
  ],
  "total": 42,
  "page": 1,
  "pageSize": 10
}
```

**API-эндпоинт:** `GET /breath_sessions/list`

---

## classify_session_time_of_day

Анализирует сессию и формирует промпт для AI-классификации времени суток. Возвращает форматированное описание сессии с инструкцией определить `timeOfDay`.

| Параметр | Тип | Обязательный | Описание |
|----------|-----|:------------:|----------|
| `sessionId` | string | да | ID сессии для анализа |

**Логика работы:**

1. Загружает сессию по ID через `GET /breath_sessions/:id`
2. Форматирует описание, упражнения и шаги в структурированный текст
3. Возвращает промпт с инструкцией выбрать одно из значений: `morning`, `midday`, `evening`

AI-ассистент анализирует возвращённый текст и предлагает классификацию.

---

## set_session_time_of_day

Обновляет поле `timeOfDay` у указанной сессии.

| Параметр | Тип | Обязательный | Описание |
|----------|-----|:------------:|----------|
| `sessionId` | string | да | ID сессии |
| `timeOfDay` | enum | да | `"morning"`, `"midday"` или `"evening"` |

**API-эндпоинт:** `PATCH /breath_sessions/:id`

**Тело запроса:** `{ "timeOfDay": "morning" }`

Возвращает обновлённую сессию.

---

## classify_all_sessions

Пакетная классификация всех неразмеченных сессий.

Параметры: нет.

**Логика работы:**

1. Загружает все сессии (с пагинацией, до 50 за запрос)
2. Фильтрует сессии с `timeOfDay === null`
3. Форматирует каждую неразмеченную сессию
4. Возвращает AI-ассистенту список для анализа с инструкцией:
   - Предложить `morning` / `midday` / `evening` для каждой
   - Запросить подтверждение у пользователя
   - Вызвать `set_session_time_of_day` для каждой подтверждённой классификации

Если все сессии уже размечены — возвращает сообщение «нечего классифицировать».

## Формат ответов

Все инструменты возвращают результат в стандартном MCP-формате:

```typescript
{
  content: [{ type: "text", text: "..." }]
}
```

При ошибке:

```typescript
{
  isError: true,
  content: [{ type: "text", text: "Error: ..." }]
}
```
